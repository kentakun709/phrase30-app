# 周回8 使う人役（user-panel）の報告 — 2026-10-20

結論: 読みが役に立つのは中国語と英語だけ。韓国語・ロシア語・タイ語では説明の無い読めない記号が並び、「読みを目で追いながら真似る」がこの3言語では起きない。P0 1件・P1 7件・P2 6件。

## P0
1. 韓・露・タイで、読みの記号を解く手がかりが画面のどこにも無い（「発音記号」のラベルも、記号の読み方も、声調の凡例も無い）。灰色の行は無視され、画面が長くなっただけになる。場所: 3言語の全マスの3行目と下の欄。

## P1
2. ローマ字のつもりで読むと違う音を覚える記号が頻繁に出る（j・tɕ・x・ʰ・ː・ʔ）。例: 韓国語は30文すべてが -jo、タイ語 máj は10文、西 xaˈpon
3. 正しいのに誤植に見える食い違い（露 01/04 の kak と kaɡ、英 02/03 の weər と weə、韓 07 の nil、中 20 の yí）。「訳はAI製」の注記と合わさって信用が下がる
4. 読みを消せない（スイッチは「ゆっくり」だけ）
5. 見た目の強さが逆（読みが一番小さく薄いが、韓・露・タイで頼れるのは読みと訳）
6. タイ語の読みが2行に折れ kʰráp/ が次の行に残る（16・17・18・20）。1マスが5行
7. 注・言い換え・タブ直下の説明に出る外国語に読みが無い（韓 01 の欄、露の説明、タイ 8・9・11、中 04、西 8・20）
8. 同じ記号が言語ごとに別の意味（中国語 à＝下がる、タイ語 à＝低い、スペイン語 ó＝強く読む）。タイ語の説明のカタカナ「カ」「カ」が区別できない

## P2
9. 英語の読みが英国式で、「NZの言い方」の説明・端末の声とずれる可能性
10. スペイン語の θ はスペイン式。中南米の声しか無い端末では s で鳴ってずれる。説明文も長い
11. 韓国語の濃音の記号が 12px では汚れに見える（02・17・18・19・20）
12. 強く読む印 ˈ がアポストロフィに見える（英 01 What's と並ぶ）
13. 下の欄にマスと同じ読みがもう一度出る（画面の約14〜24%）
14. 中国語だけ斜線が無く不統一。新機能の名前「読み」が「声: 読み込み中」「声の一覧をまだ読めていません」とかぶる

## 言語別（助かる／邪魔／止まる）
- 中国語: 全マスで漢字から音へ橋がかかる（04 zuìjìn・21 zhège duōshao qián）／ほぼ無し／20 qǐng・10 lǚxíng・27 cài のローマ字読みの罠、20 yí と辞書の違い
- 英語: 弱く言う形が見える（03・16・19 də ju、18 kən、20 kəd、01 jə）／読める短文には不要／ˈ がアポストロフィに見える、ɒ ð æ、02/03 の weər と weə
- スペイン語: ll が ʝ・v が b・z が θ と分かる程度／綴りがほぼローマ字で大半は同じ文を2回並べているだけ／ʝ・θ・x・ɾ
- ロシア語: キリル文字ゼロの人にはラテン文字の部分が唯一の足場／12・15・27 は小さい j だらけ／ɨ・ʲ・ʂ ʐ ɕ、01 kak と 04 kaɡ
- 韓国語: 短文は部分的に追える（03・21）／濃音の記号が汚れに見える／ʌ ɯ ɾ ɕ tɕ、-jo、07 nil
- タイ語: タイ文字ゼロの人には唯一の足場／16・17・18・20 で2行に折れる、kʰráp が30回／声調の記号（凡例無し）、ʔ が「?」、ː が「:」に見える

## 参考（直す方向）
- タブ直下に1行の凡例（灰色の行＝発音、j＝ヤ行、ː＝のばす、ʔ＝息を止める、音の高さの印）
- 読みの表示をオン・オフできるようにする
- 韓・露・タイだけカタカナを添えるかは、依頼の文言（「発音記号」）と食い違うので依頼主が決める

パネル総意: 韓・露・タイでは利用者は2日目から灰色の行を飛ばす。「目で追って真似る」が起きるのは英語と中国語だけ。
