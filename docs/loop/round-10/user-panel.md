# 周回10 使う人役（user-panel）の報告 — 2026-10-21

結論: P0 なし。押す→聞く→真似るの主行動は止まらない。読みが実際に役立つのは中国語と韓国語。タイ語・ロシア語は読めない灰色の行・英語とスペイン語は綴りの繰り返し。一番の問題: ローマ字の勘で外れる記号が多いのに、正しい読み方は「押せるように見えない閉じた一覧」の中にしかない。

## P1
1. 一覧（記号の読み方）が押せる物に見えない（矢印も＋も無い色付きの見出し・開いた後に閉じる印が無い・画面の上にしか無い）
2. ローマ字の勘で外れる記号が要約で正されない（ko 全30文の -jo／th 語末 j は「イ」なのに要約は「j＝ヤ行」／zh の j と si・zi が一覧に無い）
3. 言語の間で同じ印・字の意味がぶつかる（声調の印 zh/th で逆・ʌ en/ko・x・r・e・j）
4. 注・説明に出る言い換えの語に読みが無い（zh/ko/th/ru 08・09・11・ko01・ru 説明）← 周回9 で範囲外として棄却済み
5. 韓国語の詰まった音の印が一覧で崩れて見える／マスでは点にしか見えない
6. 中国語の3声の連続で印と音声がずれる可能性（10・14・16・22・26・30）／「一」の書き方とそろっていない ← 約束で辞書どおりと決めてある
7. 灰色の行を消せない ← Idea 済み

## P2
- 英語の əʊ・dʒ は一覧を足し合わせると誤読（一覧の ʒ「舌を上あごにつけない」は dʒ と逆の言い方）
- 英語の英国式が NZ・中学の辞書（米式）と違う／一覧に当たり前の行が多い・括弧の中の外国文字が読めない／一覧に音が無い
- タイ語16〜20・韓国語20で読みが2行に折り返す／画面の上3割を毎日同じ説明が占める／中国語だけ「よく出る記号」の要約が無い
- 英語の ˈ がアポストロフィに見える／ɯ と w・ɨ ɪ i・ɐ と e が見分けにくい／es10 viajar の j・x
- 英語タブの下の帯に読みが出ていない（撮影時の読み込み中の可能性）／タイ語は女性の声で全30文が男性の語尾 kʰráp

## 行動する？
