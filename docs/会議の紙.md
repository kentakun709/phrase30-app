## 調べたこと（会議の材料。出典つき）
- Web Speech API の `speechSynthesis` は iOS Safari・Android Chrome・Mac/Windows の主要ブラウザで使える。声の一覧（`getVoices`）は非同期で、iOS では最初のユーザー操作の後でないと鳴らない（MDN: SpeechSynthesis / 実機の慣例）
- タイ語・ロシア語の声は端末に入っていないことがある（iOS は設定→アクセシビリティ→読み上げコンテンツ→声 で追加できる）。だから AC7 の案内が要る
- GitHub Pages は無料プランでは public リポジトリのみ。この箱は `morse-tag`・`gads-mcp-site` と同じく public（秘密情報を置かない）

## 仮に置いたこと（追加の確認はせず、この既定で進める。違えば「直して＋一言」）
- リポジトリは **public**（GitHub Pages を無料で使うため）
- 声の選び方（周回3〜4で精密化・DECISIONS.md）: 端末内の声から選ぶ（通信する声は端末内に無い時だけ）。英語は NZ の声があれば必ず NZ。無ければ自然さ（拡張・プレミアム）を先にし、同じ自然さなら地域の近さ（英語は豪→英→愛→米）
- 他の言語の指定: 中国語 `zh-CN`（普通話。無ければ台湾の声で代用、香港の広東語は使わない）、韓国語 `ko-KR`、スペイン語 `es-ES`→`es-MX`→…、ロシア語 `ru-RU`、タイ語 `th-TH`
- 〇〇入りのフレーズは、旅行・自己紹介の場面で1つに具体化して読み上げる（08「〇〇語を話しますか？」は相手が英語を話せるかを聞く形＝中国語版「你会说英语吗？」、英語カードだけ「Do you speak Japanese?」。09・11番はその言語自身＝相手に聞かれる形。周回3で変更・DECISIONS.md）。日本語訳はその具体例の訳をマスに出し、型・注は押した後の欄に出す（周回6で マスの中 → 欄 に変更）
- 言語タブは6つ横並び（プルダウンでなくタブ。1画面で完結・押しやすい）
- 日本語訳は常時表示（要件）。~~ローマ字・ピンインなどの読みは出さない（ベータでは音で覚える）~~ → **読みを出す**（Kenta 2026-10-20 22:36「これ　発音記号と中国語はピン音も載せようか」）。中国語はピンイン、ほかの5言語は発音記号（IPA）。英語の IPA は NZ に近い非R音（英国式の表記）。韓国語・タイ語もローマ字ではなく発音記号（「発音記号」の言葉どおり）。置き場所は各マスの文の下に小さく
