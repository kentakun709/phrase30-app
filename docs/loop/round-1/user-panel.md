## 役1: ペルソナ本人（クライストチャーチ在住の30代男性・英語B1〜B2。寝る前にベッドで開く想定）

### 離脱したくなった箇所
1. **初めて開くと英語タブで「What's your name?」「Where are you from?」が並ぶ。** 自分には簡単すぎて「初心者向けのおもちゃか」と第一印象が下がる。（B。最初の言語は英語に固定: app.js 6行 `lang: 'en'`）
2. **タイ語・ロシア語・韓国語では、一番大きい20pxの太字が読めない文字だけになる。** 「คุณชื่ออะไร」を見ても手がかりがない。読み（カナ・ローマ字・ピンイン）が一切ないので、音で覚えようにも区切りすら分からない。（A: phrases.json の各項目は template/example/ja/note/audio だけで、読みの欄がない。B: 本人は読めない）
3. **声が気に入らなくても変えられない。** 「声: Eddy (es-ES)」のような表示でロボットっぽい声が鳴ったら、そこで終わる。もっと良い声の入れ方の案内もない。（A: 声を選ぶ画面がなく、案内が出るのは声がない時だけ。C: 実際にどの声になるか）
4. **声のない言語を押すと黄色い長文が出て、上部の固定ヘッダーに入ったまま消えない。** スクロールしても残り、画面の3〜4割を占める。閉じるボタンもない。（A: index.html 15行で notice が header.top の中、style.css 15行で .top が sticky、app.js 63〜64行が長文）

### 一番刺さった箇所
- **中国語 #4 の注記「教科書の 你好吗？ は日常ではあまり言わない」**（phrases.json 236行）。「教科書っぽいと信用しない」という本音に正面から答えている。英語の「sweet as＝NZの「いいね・OK」」（853行）と「NZ・英では bill、米では check」（1429行）も「自分の街の話だ」と感じる。
- カード全体が押せて、押すとオレンジに光りスピーカーが脈打つので、どこを押せば鳴るかは迷わない（style.css 28〜40行）。ダークモードにも対応していて寝る前に合う。（A）
- ただし、その注記が **11pxの薄い灰色で一番目立たない**（style.css 36行）。件数も英語5・韓国語4・中国語3・スペイン語/ロシア語/タイ語は各1。一番いらない英語に一番厚く、一番助けがほしいタイ語・ロシア語に一番薄い。（A: 件数を数えた）

### 嘘くさい／自分向けじゃないと感じた箇所
- **タイ語の例文に丁寧語の ครับ が1つも付いていない。** #28「เอาอันนี้」（1414行）、#29「เช็คบิลด้วย」（1462行）を男性が店で言うとぶっきらぼうになる。データには「丁寧に言うときは文末に ครับ（男性）」という注意書き（73行）があるのに、画面に出ない（app.js の renderTabs/renderList は languages[].note を読んでいない）。後でタイ人の友達に「krap 付けなよ」と言われたら、アプリ全体を信用しなくなる。（A＋B）
- フッターの「音声は端末の読み上げ機能」と見出しの「ベータ」で、押す前から「機械の声ね」と期待が下がる。（A＋B）
- 韓国語 #5「민수 씨는요?／ミンスさんは？」は「誰？」と一瞬引っかかる。注記で説明はされている。（A・軽い）
- **覚えたいのは挨拶と自己紹介なのに、こんにちは・ありがとう・さようなら・「日本出身です」が1つもない。** 30文のほとんどが相手に聞く質問で、自分のことを言う文や、答えを聞き取る練習がない。（A: 30項目の一覧。要件で決まった一覧だが、本人の期待とずれる）

## 役2: 懐疑役

- **「Google翻訳でいいのでは？」** 翻訳アプリには再生ボタン・ゆっくり再生・読みのローマ字がある。このアプリは読みがなく、速さは固定（app.js 111行 rate 0.9）、声も選べない。勝っているのは「選び抜いた30文＋注記」だけで、その注記が一番小さい字になっている。（B）
- **発音の正しさを誰も保証していない。** 画面には「端末の読み上げ機能」としか書かれず、誰が訳したか、ネイティブが確認したかも出ていない。（A）
- **声の選び方は、声の名前の文字だけで点数を付けている**（app.js 19〜26行）。iPhone/Mac の Safari では、スペイン語・中国語・韓国語に Eddy・Flo・Grandma・Grandpa・Reed・Rocko・Sandy・Shelley といったおもちゃ寄りの声が並ぶ可能性がある。これらは減点リストに入っていない。点数が同じなら一覧の先に並んだ声が選ばれるので、名前順で Eddy が自然な声（Mónica・Tingting・Yuna）より先に選ばれるおそれがある。（コードはA、実際の選ばれ方はC）
- **「何度でも押し直せる」という一番大事な点が、実機で守られるか分からない。** 前の声を止めてすぐ次を鳴らす作り（app.js 104行 stopAll → 125行 speak）は、Safari では新しい声まで一緒に消える例がある。消えても「キャンセルされた」扱いで黙って無視される（118行）ので、カードが光って消えるだけになる。自動テスト（Playwright）では本物の iPhone の声は確かめられない。（C）
- **「型」の行の一部は、そのまま当てはめると間違った文になる。** 韓国語 #10「〇〇서요.」（528行）は動詞の活用が必要。ロシア語 #22「Я хочу поехать 〇〇.」（1118行）は前置詞が抜けている。ロシア語 #8「по-〇〇」（446行）は普通に語を入れると文にならない。中国語 #24「哪〇〇？」（1193行）は量詞（数える言葉）が必要。分かる人が見たら一発で信用を失う。（A）
- 韓国語 #18「수영 할 줄 알아요?」（913行）は「수영할」と続けて書くのが正しい。ネイティブの友達に見られたら気づかれる。（A）
- **「うまい話すぎる」感じはほとんどない。** 大げさな約束はしていない。問題はむしろ逆で、価値を何も言っていないため「なぜこれを毎日開くのか」に答えていない。（A: 見出しは「30フレーズ」だけ）
- 30文では多言語の友達とは話せるようにならない。質問ばかりで、相手の答えを聞き取る材料がない。（A＋B）

- **声がない時の案内**（app.js 63〜64行）: 1段落に iPhone と Android の設定手順が詰め込まれていて重い。（A）
- **行き止まりの案内**: 「声の一覧をまだ読み込めていません…それでも鳴らない時は、下の案内のとおり…」（app.js 61行）と出るのに、この時は「下の案内」がどこにもない。Android の Chrome などでは、開いた瞬間にこの黄色い警告が一瞬出る可能性があり、最初から「壊れてる？」と思わせる。（文面はA、どれくらい出るかはC）
- **読み込みに失敗した時の文面**: 「file:// で開いている場合は、簡易サーバー（README）か公開URLで…」（app.js 194行）は開発者向けで、一般の人には通じない。（A）

## 役4: 行動視点（毎日開いて何度も押す、への障害）

### 押す直前のつまずき・不安
- **毎日たどり着く入口が弱い。** ホーム画面用のアイコンも、ホーム画面に置くための設定ファイル（manifest）もない（index.html 3〜10行）。URLは GitHub Pages のもの。ホーム画面に置いても、ページの縮小画像のアイコンになるだけ。（A）
- **初回に「光るのに鳴らない」。** 押した瞬間に光らせる作り（app.js 123行）なので、マナーモードや音量0で音が出なくても、光って消えるだけで何も言われない。声がない時以外の「聞こえない時」の案内がない。（コードはA、iPhone のマナーモードで本当に無音になるかはC）
- **電波がないと開けない。** 毎回データを取りに行く作り（app.js 190行 cache:'no-cache'）。電波の弱い所では、上の開発者向けエラーになる。（A、場面はB）
- **画面を消したり他のアプリに移ったりすると止まる**（app.js 184行）。自動で繰り返す・30文を続けて流す・ゆっくり再生もない。「繰り返し聞くことが最重要」なのに1回ずつ指で押すしかなく、寝転んで聞き流すような使い方ができない。（A）
- **続ける仕掛けがない。** 覚えた印・今日聞いた数・前回どこまで聞いたか、どれも残らない（残すのは言語だけ: 163行）。毎回 #01 から始まり、旅行の #20〜30 まで指が届かない。（A＋B）
- 声を追加するには、アプリを出て設定へ行き、数十〜数百MBをダウンロードする必要がある。案内はあっても、実際にやる人は少ない。（B）

### 選択肢の多さ・情報の順番
- 選ぶもの自体は少なく（6タブ×30枚）、そこは良い。
- 問題は順番。使い方はフッターで一番最後、一番価値のある注記は一番小さく最下段、価値の薄い「型」が注記より上にある。
- 自己紹介・質問・旅行の区切りがなく、30枚をひたすらスクロールする。（A）
- 6タブを横に均等割りしている（style.css 18行）。幅320〜375pxの画面では「Español」「Русский」「スペイン語」がぎりぎり。（C）

### 最終判断: 続けない（最初の週で離れる）
本音: 「最初の夜は、友達の言語で10回くらい押す。声がまともならスペイン語と中国語は2〜3日続く。でもタイ語とロシア語は読めないし、丁寧語が抜けていると後で知って冷める。声が嫌でも変えられない。2週目に開く理由がなく、ブックマークの奥に沈む。結局、ゆっくり再生と読みがある翻訳アプリに戻る」（B。声の部分はC）

## パネル総意: 最も致命的なユーザー離脱理由
「音で覚える」ことが唯一の価値なのに声が端末まかせで、機械っぽい声や無音に当たっても本人は声を変えられず理由も知らされないため、最初の数タップで冷めて二度と開かない。
