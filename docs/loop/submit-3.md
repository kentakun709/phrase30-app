問い: この形で受け取ってよいか

受け取りを勧める理由は3点です。

 2点目は、「もっとゆっくり」は0.5倍で、文にも単語にも効きます。普通0.9倍・ゆっくり0.7倍はそのままです
 3点目は、自動の試験59本が今日（11/06 17:43）全部通り、公開版の中身も手元と一致しています
