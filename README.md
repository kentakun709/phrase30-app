# phrase30-app — 30フレーズ音声アプリ（ベータ）

日常会話の基本30フレーズを、選んだ言語の自然な表現＋日本語訳で一覧し、**タップ1回で発音を聞ける**スマホ向けWebアプリ。
6言語（英語＝NZ英語優先・中国語（普通話）・韓国語・スペイン語・ロシア語・タイ語）×30＝180表現。登録・課金・APIキーなし。

- 要件の原文: `docs/調査/2026-10-19_要件定義書v0.1.md`（Chatwork 2026-10-19 13:30・判子② 2026-10-20 06:17）
- 完成の条件・見せる場面: `docs/会議の紙.md`
- 英語学習ゲーム（`eigo-game`）とは別案件

## 使い方（公開版）
GitHub Pages の URL をスマホのブラウザで開く（URL は `docs/CURRENT.md`）。
1. 一番上の言語タブで言語を選ぶ（帯は下へ送っても残る）。タブのすぐ下に、その言語の言い方の注意が1〜2行
2. 30フレーズは1つの枠（四角形）の中に表の形で並ぶ。各マスは 番号・その言語の文・読み（中国語はピンイン・ほかは発音記号。言語の説明の下の「記号の読み方」を開くと、その言語の記号が全部）・日本語訳（原本 v0.1 の「3列×10」どおり、幅600以上は 1〜10・11〜20・21〜30 を上から下へ。スマホ幅では 2列×15＝左 1〜15・右 16〜30）。区切りの名前（初対面で聞く・使い回せる質問・旅行と店で）は 1・13・20番のマスの番号の横
3. マスをタップすると、その言語の音声が鳴る（何度でも。別のマスを押すと前の音声は止まる）。押した文は枠のすぐ下の欄に大きく出て、言い換えの型（〇〇入り）と一言の注もそこに出る。枠が画面より長い時は欄が画面の下端に留まるので、押した瞬間に見える。欄を押すともう一度鳴る。「ゆっくり」（右上）を押すと 0.7倍で鳴る
4. 端末にその言語の音声が無い時は、同じ欄の上に案内（言語名と、設定で声を足す手順）が出る。鳴り始めない時も「もう一度押してください」と出る。使っている声と「もっと自然な声に」は欄の最下段
5. スクロール位置は言語ごとに覚える（鍵 phrase30.scroll.v2）

## 手元で動かす
静的サイト（`index.html`＋`app.js`＋`data/phrases.json`）。サーバー不要だが、`fetch` の都合で file:// ではなく簡易サーバーで開く:
```
cd phrase30-app && python3 -m http.server 8000
# → http://localhost:8000/
```

## 作り
- `index.html` … 画面1枚（固定の帯 `.top`＝タイトル・ゆっくり・言語タブ／言語の説明 `#langnote`／枠 `#board` の中に表 `#list`（30マス `.card`）／欄 `#dock`（画面の下端に留まる）＝案内 `#notice`・押した文 `#detail`・声の表示／声の足し方の折り畳み）
- `app.js` … 言語切替・表の描画（並びは `style.css` の列: スマホ 2列×15・幅600以上 3列×10）・押した文の欄・Web Speech API の声の選び方・再生中の見た目・再タップで止めて鳴らし直す（`speechSynthesis.cancel()` してから `speak()`＝読み上げの列を溜めない。鳴っていた時だけ 80ms 待ってから鳴らす）・鳴り始めない時の見張り（2.5秒）
  - 声の選び方: **端末内の声（localService）から選ぶ**（通信する声は端末内に無い時だけ）。その中で上から順に比べる（足し算ではない）: 英語は NZ の声があれば必ず NZ → 自然さ（名前・識別名に premium／enhanced／拡張／プレミアム なら +5、compact −3、eloquence／Eddy などの機械声 −10）→ 地域の近さ（英語なら豪 → 英 → 愛 → 米）→ 端末の既定の声 → 名前の順（列挙順に左右されない）。中国語は香港の広東語の声を使わず、台湾の声は普通話の声が無い時だけ
- `data/phrases.json` … 30フレーズ×6言語＋小見出し（`sections`）。各項目は `template`（原文の型・〇〇入り）と `example`（読み上げる具体例）と `reading`（example の読み。表記の約束は `docs/調査/2026-10-20_読みの表記の約束.md`・決め方は `docs/DECISIONS.md`）と `ja`（日本語訳・例文の訳）と `note`（一言）を分けて持つ。タイ語の例文は男性の丁寧形（文末 ครับ）。`audio` 欄に音声ファイルの**同じサイト内の相対パス**（例 `audio/th/01.mp3`）を入れると、Web Speech API の代わりにそれを鳴らす（高品質TTSで事前生成した音声への差し替え口。読めない時は案内を出して読み上げに戻る）。音声ファイルの置き場は `audio/`（git に載せる）
- `scripts/check-data.mjs`・`scripts/check-no-external.mjs` … 件数（6・30・180）と中身の点検、外部通信・鍵・課金・外部URLの audio が無いことの点検（`npm run check`）
- `tests/app.spec.mjs` … Playwright 24本（周回8で読みの試験 AC11 を足した）（この Mac の Chrome・幅390。見た目の試験 AC10b は幅1024。`PW_PORT` で受け口の番号を変えられる）。読み上げは差し替えて呼び出しの順番を見る。`scripts/probe-voices.mjs` は本物の読み上げで言語ごとの声と再生を記録する（音が出る）

## 既知の制約（ベータ）
- `overflow-x:hidden` は html だけに付ける（body に付けると帯と欄の sticky が効かない。周回6で発覚）
- 横向き（画面の高さ 500px 未満）では、押した文の欄は画面の下端に留まらず枠の下に出る（表がほとんど見えなくなるため）
- 声の有無・質は端末まかせ（6言語すべての音質は保証しない）。iPhone/Android では設定で高品質の声を追加できる
- Chrome 内蔵の Google の声（端末内に声が無い時だけ使う）では、読み上げ時にブラウザが Google と通信することがある（鍵・課金・ログインは不要）
- 自動試験はこの Mac の Chrome（幅390）だけ。iPhone Safari・Android Chrome の実機は未確認。訳と読みはAIが作り（読みはハヤトと東条の2者独立＋機械照合）、ネイティブの検品は未実施
