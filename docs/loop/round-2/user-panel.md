## パネル総意: 最も致命的なユーザー離脱理由1つ

最初のタップで鳴る端末の初期の声が機械っぽいのに、自然な声にする手順は30枚の下の小さな注記にしか無く、冷めたその瞬間に救えないため、2回目を開かない。
