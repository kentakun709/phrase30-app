# 読みの表記の約束（phrase30-app・学習者向け・各マスに常時表示）

**表記の規則はこの紙1枚が正本**（周回9で DECISIONS.md から規則をここへ集めた。DECISIONS.md には理由と他の案だけを残す）。
機械の点検は `scripts/check-data.mjs`（IPA の文字の集合は `IPA_RE` が正本）。

## 共通
- 対象は各文の `example`（実際に読み上げる文）。型（〇〇入り）の読みではない。1文につき1行
- 文末の ? ! . と、引用符（" “ ” ' ‘ ’ 「 」 « »）・読点は付けない
- 単語の間は半角スペース。**語の単位は辞書の見出し語**（複合語・ハイフンでつないだ語も1語として続けて書く）。ただし言語の節に単位を書いた言語はそちらを優先する（zh＝汉语拼音正词法・ko＝分かち書き）

## zh（中国語）＝ピンイン（漢字を含めない・声調記号つき・IPA ではない）
- 単語ごとにまとめて書く（汉语拼音正词法。例: 你叫什么名字 → nǐ jiào shénme míngzi）。全部小文字
- 軽声は記号なし（什么 shénme・名字 míngzi・时候 shíhou・谢谢 xièxie・哪里 nǎli）
- 一・不 の変調は実際の発音で書く（一下 yíxià・一遍 yí biàn・一路 yí lù・不客气 bú kèqi）。第3声の連続（你好）は辞書どおり nǐ hǎo のまま
- 多音字は話し言葉の読み（谁 shéi）
- 文の中のラテン文字（Wi-Fi）は文の表記どおりに残す（「全部小文字」の例外）

## en・es・ru・ko・th＝IPA（前後を / / で囲む）
- 強勢は ˈ のみ（第2強勢は付けない）。ˈ は強い音節の頭（子音の前）に置く（es estuˈdjando・ru mɐˈɡlʲi）
- 内破音の記号 ̚・音節の区切り点・連結の記号 ‿・破擦音のつなぎ線 ͡ は使わない（ts・tɕ と書く）

### en（英国式の非R音の表記・NZに近い）
- DRESS は /e/、LOT は /ɒ/、GOAT は /əʊ/、NEAR は /ɪə/。長音 ː は付ける
- 強勢: 内容語と疑問詞（what・how・where・when・which・who・why）に ˈ。1音節の語にも付ける（どの語を強く言うかを見せるため）。2音節以上の語は語の強勢を残す（about /əˈbaʊt/・because・again）。機能語（you・to・a・the・do・can・could 等）は弱形で ˈ なし（/ju/ /tə/ /ə/ /də/ /kən/ /kəd/）
- 但し書き: 対比で焦点になる代名詞は強形で ˈ（How about you? の you /ˈjuː/）。文末に残る前置詞は強形で ˈ（Where are you from? の from /ˈfrɒm/）。指示代名詞 this・that は文の焦点なら ˈ（How much is this? /ˈðɪs/・Who is that? /ˈðæt/）、焦点でなければ ˈ なし（say that again の that）
- 文頭・文中の助動詞 have は h を残した弱形 /həv/。本動詞の have と please は ˈ あり
- this one は this に強勢（one は代名詞で弱い）
- 母音の前の語末の r は繋ぎの r を書く（where are → /ˈweər ə/）。母音の前でなければ書かない（where do → /ˈweə də/）

### es（音素表記）
- ll・y は /ʝ/（yeísmo）。b/d/g は /b d ɡ/（β ð ɣ は使わない）。r と rr は /ɾ/ と /r/。語頭と n・l・s の後の r も /r/（repetirlo /repeˈtiɾlo/・recomienda）
- c(e,i)・z は /θ/（スペイン式。声の優先がスペイン es-ES のため。中南米では /s/ と言語の説明に書く）
- 外来語の sh は /ʃ/（sushi /ˈsuʃi/。ʃ は外来語にだけ出る）
- 二重母音の半母音は /j/ /w/（autobús /awtoˈbus/・tiempo /ˈtjempo/）
- 強勢: 強い語に ˈ。1音節の強い語にも付ける（疑問詞 qué・quién、tú、vez、ir 等）。定冠詞（el・la・los・las）・前置詞・接続詞（y・porque 等）・目的格の代名詞・繋辞の es は ˈ なし（不定冠詞 una は強勢を持つので ˈ あり）

### ru（実際の発音に近い表記）
- 強勢 ˈ・軟音 ʲ・母音の弱化（ɐ ɪ ə）を書く。軟子音の後の語末の無強勢 -е は /ɪ/（-те /tʲɪ/）。j の後の語末の無強勢 -е（-ое・-ее）は /ə/（какое /kɐˈkojə/）
- **1音節の語には ˈ を付けない**（ロシア語の辞書の慣例。英・西と違う）
- ё は /o/（ɵ は使わない）。強勢のある э と、ш・ж・ц の後の е は /ɛ/（ˈɛtə・pʊtʲɪˈʂɛstvəvətʲ）。無強勢の э は /ɪ/（аэропорта /ɐɪrɐˈportə/）。語頭の無強勢 а・о は強勢からの距離に関わらず /ɐ/
- 軟子音の前の子音も軟らかくなる所は書く（есть /jesʲtʲ/）。強勢から2つ以上前の о・а は /ə/、すぐ前は /ɐ/（по-английски /pəɐn…/）
- 語の境を越える有声化の同化は書く（как дела /kaɡ dʲɪˈla/・вас зовут /vaz zɐˈvut/）。в・母音・j の前では起きない（как вас /kak vas/・у вас есть /u vas jesʲtʲ/）
- -ться・-тся は /tsə/
- 動詞の強勢は辞書の現在形のとおり（вы у́чите・вы лю́бите・сто́ит＝値段）。命令形（учи́те）や別の動詞（стои́т＝立つ）と取り違えない
- 前置詞（в・у 等）は別の語として書く。ハイフンでつないだ語は1語（по-английски /pəɐnˈɡlʲijskʲɪ/・когда-нибудь /kɐɡˈdanʲɪbʊtʲ/ ＝単独の形。были の前では同化して /…bʊdʲ/・вай-фай /vajˈfaj/）

### ko（実際の発音・音の変化を反映）
- 語（分かち書き）ごとにスペース。強勢記号なし。激音 ʰ・濃音 ͈（例 k͈ s͈ tɕ͈）
- 예요 は標準発音 /jejo/。ㅐ（ㅙ の中の ㅐ も。왜 /wɛ/・됐 /twɛs͈/）は /ɛ/・ㅔ は /e/（標準発音法の区別）。계 は /kje/
- 語頭の平音は無声のまま、語の中だけ有声（잘 지내세요 /tɕal tɕinɛsejo/・도와주시겠어요 /towadʑuɕiɡes͈ʌjo/）
- ㅅ・ㅆ は い の前で /ɕ/・/ɕ͈/（씨 /ɕ͈i/・시예요 /ɕ͈ijejo/）
- ㄴ 挿入・濃音化・激音化は、分かち書きの境を越えても続けて言う所は書く（무슨 일 /musɯn nil/・할 줄 /hal tɕ͈ul/・몇 시 /mjʌt ɕ͈i/・초밥 좋아하세요 /tɕʰobap tɕ͈oahasejo/＝詰まる音 ㄱ ㄷ ㅂ で終わる語のあとの平音は濃音）。連音は分かち書きの境を越えたら書かない（적 있으세요 /tɕʌk is͈ɯsejo/）

### th
- 声調は母音の上の記号（中＝なし・低 ̀・下降 ̂・高 ́・上昇 ̌）。有気音 ʰ・長母音 ː
- 疑問の ไหม は話し言葉の高声 /máj/。ได้ /dâj/・เรียน /rian/
- 語＝辞書の見出し語（タイ王立学士院辞典の見出し語。複合語も1語。ถ่ายรูป・ว่ายน้ำ は動詞＋目的語の句なので2語: ยินดี /jindiː/・รู้จัก /rúːtɕàk/・ทำงาน /tʰamŋaːn/・เพราะว่า /pʰrɔ́ʔwâː/・ที่ไหน /tʰîːnǎj/・แค่ไหน /kʰɛ̂ːnǎj/・ที่นี่ /tʰîːnîː/・เมื่อไหร่ /mɯ̂aràj/・เท่าไหร่ /tʰâwràj/・อันนี้ /ʔanníː/・ตอนนี้ /tɔːnníː/・รถไฟ /rótfaj/・รถเมล์ /rótmeː/・สนามบิน /sànǎːmbin/・ไวไฟ /wajfaj/・เช็คบิล /tɕʰékbin/・แนะนำ /nɛ́ʔnam/）。重ね言葉（สบายๆ）は2語
