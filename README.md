# phrase30-app — 30フレーズ音声アプリ（ベータ）

日常会話の基本30フレーズを、選んだ言語の自然な表現＋日本語訳で一覧し、**タップ1回で発音を聞ける**スマホ向けWebアプリ。
6言語（英語＝NZ英語優先・中国語（普通話）・韓国語・スペイン語・ロシア語・タイ語）×30＝180表現。登録・課金・APIキーなし。

- 要件の原文: `docs/調査/2026-10-19_要件定義書v0.1.md`（Chatwork 2026-10-19 13:30・判子② 2026-10-20 06:17）
- 完成の条件・見せる場面: `docs/会議の紙.md`
- 英語学習ゲーム（`eigo-game`）とは別案件

## 使い方（公開版）
GitHub Pages の URL をスマホのブラウザで開く（URL は `docs/CURRENT.md`）。
1. 上の言語タブで言語を選ぶ（タブの下に、その言語の言い方の注意が1行出る）
2. フレーズのカードをタップすると、その言語の音声が鳴る（何度でも。別のカードを押すと前の音声は止まる）。「ゆっくり」を押すと 0.7倍で鳴る
3. 端末にその言語の音声が無い時は、カードの上に案内（言語名と、設定で声を足す手順）が出る。鳴り始めない時も「もう一度押してください」と出る
4. 30枚は「自己紹介・会話を始める（1〜12）」「使い回せる質問（13〜19）」「旅行と店で（20〜30）」の3つに分けてある

## 手元で動かす
静的サイト（`index.html`＋`app.js`＋`data/phrases.json`）。サーバー不要だが、`fetch` の都合で file:// ではなく簡易サーバーで開く:
```
cd phrase30-app && python3 -m http.server 8000
# → http://localhost:8000/
```

## 作り
- `index.html` … 画面1枚（言語タブ・30カード・案内）
- `app.js` … 言語切替・Web Speech API の声の選び方・再生中の見た目・再タップで止めて鳴らし直す（`speechSynthesis.cancel()` してから `speak()`＝読み上げの列を溜めない。鳴っていた時だけ 80ms 待ってから鳴らす）・鳴り始めない時の見張り（2.5秒）
  - 声の選び方: 言語ごとの優先順（英語は `en-NZ` → `en-AU` → `en-GB` → `en-IE` → `en-US` → その他の英語）で候補を絞り、**端末内の声（localService）を優先**、名前・識別名に compact／eloquence／Eddy などの機械っぽい印があれば減点、premium／enhanced なら加点。中国語は香港の広東語の声を使わず、台湾の声は普通話の声が無い時だけ
- `data/phrases.json` … 30フレーズ×6言語＋小見出し（`sections`）。各項目は `template`（原文の型・〇〇入り）と `example`（読み上げる具体例）と `ja`（日本語訳・例文の訳）と `note`（一言）を分けて持つ。タイ語の例文は男性の丁寧形（文末 ครับ）。`audio` 欄に音声ファイルの**同じサイト内の相対パス**（例 `audio/th/01.mp3`）を入れると、Web Speech API の代わりにそれを鳴らす（高品質TTSで事前生成した音声への差し替え口。読めない時は案内を出して読み上げに戻る）。音声ファイルの置き場は `audio/`（git に載せる）
- `scripts/check-data.mjs`・`scripts/check-no-external.mjs` … 件数（6・30・180）と中身の点検、外部通信・鍵・課金・外部URLの audio が無いことの点検（`npm run check`）
- `tests/app.spec.mjs` … Playwright 12本（この Mac の Chrome・幅390）。読み上げは差し替えて呼び出しの順番を見る。`scripts/probe-voices.mjs` は本物の読み上げで言語ごとの声と再生を記録する（音が出る）
