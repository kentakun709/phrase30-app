# 周回9 使う人役（user-panel）の報告 — 2026-10-21

総意: タイ・韓国・ロシア語の読みは、ほぼ全マス（30/30・24/30・29/30）に「そのタブの説明に無い記号」かローマ字読みの罠の j を含み、「読みを目で追って真似る」が成り立たない。中国語は全マスで助かる。英語は弱く読む形が助かる。

## P0
- P0-1 タイ・韓国・ロシア語で「読みを目で追って真似る」が成り立たない（凡例が一部の記号しか説明していない）。止まる例: th 01 tɕʰɯ̂ː・16 tɕʰɔ̂ːp・05 lɛ́ːw・20 kʰráŋ・13 kʰɤːj／ko 04 tɕal tɕinɛsejo・02 oɕʌs͈ʌjo・20 taɕi・14 sadʑin・01 iɾɯmi／ru 01 zɐˈvut・06 ˈotɕɪnʲ・17 ʂto・20 pɐˈʐalʊstə・29 ɕːot。ロシア語の「o と書いてアと読む」が説明の無い ɐ・ə で書かれていて伝わらない
  - 説明に無い記号を含むマス: th 30/30（j を除いても 22/30）・ko 24/30・ru 29/30

## P1
1. j がローマ字読みの罠（j＝ヤ行の説明は韓国語タブにしか無い。th máj・àraj・jùː／ru ja・jesʲtʲ／es ˈtjempo・ˈkjeɾo・ˈkjen）
2. 同じ印が中国語とタイ語で違う意味（ǎ・à）
3. ピンインの文字の読み方（q・x・zh・z・c・r・e・ü）の説明が無い（zh 20 qǐng・21 qián・16 xǐhuan・04 zuìjìn zěnmeyàng・09 xué・10 lǚxíng・06 rènshi）
4. 画面がごちゃつき消せない（th 16・17・18・20 で読みが2行・20 は訳が下の帯に隠れる・説明が th 5行・ko 4行・es は6行以上の見込み・下の帯で読みが二重）
5. 置き換え語と言い換えの文に読みが無い（th 08・09・11 ญี่ปุ่น／ko 08・09／ko 01 の帯の 성함이 어떻게 되세요?／ru 08・09・11・説明の Как тебя зовут?／zh 08・09・11 日语）
6. 記号の説明が1か所だけ・段落の後ろ半分にある（言語の注意書きと区切りが無い。送ると消える）

## P2
- 英語の説明は NZ・記号は英国式・声は豪州英語で3種類
- ʔ が「?」に見える（th 05・16）
- ˈ がアポストロフィに見える（英語の説明で行頭に浮く・17番の引用符と並ぶ）
- 韓国語の濃音の印の説明は「s͈ の下の印」だが t・k・ɕ・tɕ の下にも付く
- 中国語の3声の連続（10・14・22・30）で印と声がずれる・「ǎ 下がって上がる」をそのまま真似ると nǐ が不自然
- スペイン語・英語は読みが綴りの繰り返しに近い（v を b で読む所は価値があるが説明が無い）
- タイ語は全マス男性形 kʰráp

## 発見
「タイ語の声調記号なんて読めない」と思っていたが、声調の説明は一番分かりやすかった。止まる原因は声調ではなく子音と母音の記号（tɕ・ɯ・ɔ・ɛ・ŋ・j）
