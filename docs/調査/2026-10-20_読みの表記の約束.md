# 読みの表記の約束（phrase30-app・学習者向け・各マスに常時表示）

共通: 対象は各文の `example`（実際に読み上げる文）。1文につき1行。文末の ? ! . は付けない。
- **zh（中国語）＝ピンイン**（漢字を含めない・声調記号つき・IPAではない）
  - 単語ごとにまとめて書く（汉语拼音正词法。例: 你叫什么名字 → nǐ jiào shénme míngzi）。全部小文字
  - 軽声は記号なし（什么 shénme・名字 míngzi・时候 shíhou・谢谢 xièxie）
  - 一・不 の変調は「実際の発音」で書く（一下 yíxià・不客气 bú kèqi）。第3声の連続（你好）は辞書どおり nǐ hǎo のまま
- **en・es・ru・ko・th＝IPA**。前後を / / で囲む。単語の間は半角スペース
  - en: 英国式の非R音の表記（NZに近い）。DRESS は /e/、LOT は /ɒ/、GOAT は /əʊ/、NEAR は /ɪə/。強勢は ˈ のみ（第2強勢は付けない）。内容語に強勢、機能語（you, to, a, the 等）は自然な弱形（/ju/ /tə/ /ə/）。長音 ː は付ける
  - es: 音素表記。強勢 ˈ。ll・y は /ʝ/（yeísmo）。b/d/g は /b d ɡ/（β ð ɣ は使わない）。r と rr は /ɾ/ と /r/
  - ru: 実際の発音に近い表記。強勢 ˈ・軟音 ʲ・母音の弱化（ɐ ɪ ə）を書く
  - ko: 実際の発音（音の変化を反映）。語（分かち書き）ごとにスペース。強勢記号なし。激音 ʰ・濃音 ͈（例 k͈）
  - th: 声調は母音の上の記号（中＝なし・低 ̀・下降 ̂・高 ́・上昇 ̌）。有気音 ʰ・長母音 ː。語ごとにスペース
